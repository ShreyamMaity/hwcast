Setup hwcast with an agent

Pick the coding agent you use. It opens with a prepared prompt; you press Enter. The agent checks your hardware, asks you a few questions (port, where you will view the dashboard, sensor driver, install folder) and only then installs hwcast. You approve every change, and Windows asks for admin permission when needed.

Claude Code

One click opens Claude with the prompt filled in. The terminal button works once you have used Claude Code in a terminal at least once.
